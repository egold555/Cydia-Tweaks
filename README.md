# Cydia Tweaks

My old jailbreak tweaks, ringtones and scripts from 2016–2019, originally published on my Cydia repo (cydia.golde.org).

Each one used to be its own GitHub repo. They're now combined here, one folder per tweak, with the full commit history of each kept (`git log -- <folder>/`).

These are unmaintained and kept for history.
